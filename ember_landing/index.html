Trust & Transparency

믿어달라고 하기보다,
확인할 수 있게 만들겠습니다.

Ember는 개인 개발 프로젝트입니다. 따라서 거대한 서비스처럼 이름만으로 신뢰를 요구하기보다, 무엇을 만들고 있는지, 어떻게 동작하는지, 어떤 방향으로 운영하는지를 가능한 한 명확하게 공개하려 합니다.

PROJECT IDENTITY

누가 만들고 있나요?

Ember는 플레이디버그연구소에서 진행하는 개인 개발 프로젝트입니다. 중앙 플랫폼을 운영하는 대규모 서비스가 아니라, 필요한 사람의 컴퓨터에서 직접 실행할 수 있는 작은 공간을 만드는 것을 목표로 합니다.

CURRENT MODEL

왜 무료인가요?

현재 Ember는 별도의 이용료나 구독료를 받지 않습니다. 체험하기 페이지에서는 사용자가 원할 경우 「광고 보기로 후원하기」 기능을 통해 자발적으로 프로젝트를 후원할 수 있습니다. 광고 시청은 선택 사항이며 Ember의 기본 사용을 제한하지 않습니다. 현재는 이 외에 별도의 데이터 판매나 강제적인 수익화 구조를 운영하고 있지 않습니다.

SELF HOSTED

데이터는 어디에 있나요?

Ember의 핵심 구조는 중앙 플랫폼에 모든 데이터를 모으는 것이 아니라, 사용자의 컴퓨터에서 직접 서버 공간을 실행하는 셀프호스트 방식입니다. 따라서 데이터를 어디에 저장하고 어떤 경로로 전달하는지는 사용 중인 Ember 서버의 구조와 설정을 기준으로 확인할 수 있습니다.

TRANSPARENCY

앞으로 무엇이 바뀔 수 있나요?

Ember의 수익 모델이나 데이터 활용 방식이 변경된다면 현재와 달라진 부분을 별도로 공개하는 것을 원칙으로 합니다. 지금의 약속을 영원한 약속이라고 포장하기보다, 프로젝트가 어떻게 변화해 왔는지를 기록하는 방식을 지향합니다.

신뢰는 선언보다 확인에 가깝다고 생각합니다.

Ember가 안전하다고 단순히 주장하는 것만으로는 충분하지 않습니다. 그래서 프로젝트의 구조, 배포물, 네트워크 동작과 데이터 처리 방식을 가능한 범위에서 확인할 수 있는 방법을 함께 제공하려 합니다.

배포물 공식 배포 경로를 통해 배포되는 프로그램을 사용하세요.
동작 확인 네트워크 연결과 로컬 데이터 저장 구조를 직접 확인할 수 있습니다.
변경 기록 버전 업데이트와 주요 기능 변경을 지속적으로 기록합니다.

※ Ember는 오픈소스 프로젝트가 아닙니다. 따라서 모든 내부 구현을 공개한다는 의미가 아니라, 사용자가 프로그램의 동작을 이해하고 검증할 수 있는 경로를 점진적으로 넓혀가는 것을 목표로 합니다.

인터넷이 꼭 거대한 광장일 필요는 없습니다.

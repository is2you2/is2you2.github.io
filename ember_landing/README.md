# Ember Landing V2

기존 Ember 랜딩 페이지의 방향을 유지하면서, 제품 정의를 **"기한이 있는 작은 프로젝트 공간"**으로 재정렬한 독립형 랜딩 프로토타입입니다.

## 핵심 변경

- Hero에서 "초안 도구"보다 "기한이 있는 프로젝트 공간"을 우선 설명
- `사람을 모으고 → 함께 만들고 → 끝나면 불을 끈다`를 핵심 흐름으로 승격
- 채널/자료/기한/self-hosted를 실제 제품 화면처럼 보여줌
- AI 관련 메시지는 제품 정체성이 아니라 보조 철학으로 배치
- 기존 Ember의 주황/노랑/파랑/짙은 남색과 기존 SVG 자산 재사용

## 파일

- `index.html` — 랜딩 페이지
- `style.css` — 스타일
- `assets/` — 기존 Ember 번들에서 가져온 시각 자산
